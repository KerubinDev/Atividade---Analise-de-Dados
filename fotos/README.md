# Organização das Fotos do Experimento

Este diretório contém as fotografias tiradas durante o experimento de crescimento de feijões. As fotos estão organizadas em pastas por dia de experimento.

## Estrutura de Pastas Sugerida

```
fotos/
├── dia_01/
│   ├── grupo_a_1.jpg  # Grupo A - Água da torneira, copo 1
│   ├── grupo_a_2.jpg  # Grupo A - Água da torneira, copo 2
│   ├── grupo_b_1.jpg  # Grupo B - Água mineral, copo 1
│   ├── grupo_b_2.jpg  # Grupo B - Água mineral, copo 2
│   ├── grupo_c_1.jpg  # Grupo C - Água com açúcar, copo 1
│   └── grupo_c_2.jpg  # Grupo C - Água com açúcar, copo 2

│   └── ...
```

## Dicas para Tirar as Fotos

1. **Consistência**: Tire as fotos sempre na mesma posição, distância e iluminação para facilitar a comparação.

2. **Iluminação**: Use iluminação natural indireta sempre que possível, evitando sombras fortes.

3. **Fundo**: Use um fundo uniforme (branco ou preto) para destacar as plantas.

4. **Escala**: Inclua uma régua ou outro objeto de referência para dar noção de escala.

5. **Ângulos**: Tire fotos de pelo menos 2 ângulos diferentes:
   - De cima para visualizar a distribuição das folhas
   - De lado para visualizar a altura

6. **Resolução**: Use a maior resolução possível do seu smartphone ou câmera.

7. **Estabilidade**: Use um suporte ou tripé se disponível para evitar fotos tremidas.

## Nomenclatura dos Arquivos

Use um padrão consistente para nomear os arquivos de foto:

`dia_XX_grupo_Y_copo_Z.jpg`

Onde:
- XX é o número do dia (01, 02, 03...)
- Y é a letra do grupo (a, b, c)
- Z é o número do copo (1 ou 2)

Exemplo: `dia_07_grupo_b_copo_1.jpg`

## Fotos Adicionais

Além das fotos regulares a cada 2 dias, tire fotos extras quando observar:
- Primeira germinação em cada grupo
- Aparecimento da primeira folha
- Qualquer anomalia ou característica interessante
- Comparação lado a lado de todos os grupos no último dia
